# 🎨 Drawing App – Front-End Development Project

## 📌 Project Overview

Drawing App is an interactive web application developed using HTML5, CSS3, and JavaScript. It allows users to create digital drawings directly in their browser using different drawing tools and customizable options.

The project focuses on interactive functionality, JavaScript event handling, and creating a user-friendly drawing experience.

## ✨ Key Features

- Interactive drawing canvas
- Draw using mouse movements
- Adjustable brush size
- Multiple color options
- Eraser functionality
- Clear canvas option
- Responsive user interface

## 🛠️ Technologies Used

- HTML5 – Application structure
- CSS3 – Styling and layout
- JavaScript – Drawing functionality and user interactions
- HTML Canvas API – Drawing implementation

## 📱 Responsive Design

Designed to provide a smooth experience across desktop, tablet, and mobile devices.
